# soalin-bank
Bank soal untuk app Soalin. Diambil otomatis oleh app saat online.

Update soal: di repo Soalin jalankan
`node scripts/export-bank.js ../soalin-bank`, lalu commit dan push repo ini.

Gambar (`images/packages/`) tidak disimpan di sini dulu: salin manual dari repo Soalin
(`images/packages/` → `soalin-bank/images/packages/`), atau jalankan export di atas yang juga menyalinnya.
